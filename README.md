
# TaskFlow

TaskFlow — веб-приложение для управления задачами
и совместной работы команды.

## Версия

0.0.1

## Технологии

- Python
- FastAPI
- Uvicorn
- Jinja2
- Docker

## Запуск через Docker

Скачать образ:

```bash
docker pull danildol/taskflow:0.0.1
```

Запустить приложение:

```bash
docker run --rm -p 8080:8080 danildol/taskflow:0.0.1
```

После запуска открыть в браузере:

http://localhost:8080
